# 赣南脐橙价格数据监控与分析

基于公开数据对赣南脐橙（普通脐橙）批发与零售价格进行采集、清洗、分析并可视化。

## 项目简介

- **数据来源**：全国农产品批发市场价格信息系统（农业农村部）、电商平台公开零售价格
- **技术栈**：Python（pandas）+ MySQL + pyecharts
- **分析内容**：价格季节性波动、年度同比、批发-零售价差
- **产出**：数据清洗脚本、MySQL 建表与分析 SQL、可视化大屏
