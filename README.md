# 赣南脐橙价格数据监控与分析

基于公开数据对赣南脐橙（普通脐橙）批发与零售价格进行采集、清洗、分析并可视化。

> 🔗 **可视化大屏在线预览**：https://zhong-yi-xia.github.io/navel-orange-price-analysis/


## 项目简介

- **数据来源**：全国农产品批发市场价格信息系统（农业农村部）、电商平台公开零售价格
- **技术栈**：Python（pandas）+ MySQL + pyecharts
- **分析内容**：价格季节性波动、年度同比、批发-零售价差
- **产出**：数据清洗脚本、MySQL 建表与分析 SQL、可视化大屏

## 分析结论

1. **季节性**：上市季（11-2月）批发均价 6.16 元/kg，淡季 6.79 元/kg，淡季高出 10.3%——集中上市期供给充足压低价格；5-8 月为全年价格高点（约 7.2-7.4 元/kg）。
2. **年度走势**：2022 年 7.22 → 2023 年 7.51 → 2024 年 5.67 → 2025 年 6.62 → 2026 年 4.79 元/kg，2026 年处于近五年低位。
3. **批发-零售价差**：电商零售中位价 6.63 元/斤，同期批发价 2.30 元/斤，零售约为批发的 2.9 倍（流通加价约 189%），零售单价区间 3.80~9.98 元/斤。

## 数据说明

- 批发价来源：北京新发地农产品批发市场（2022-01-01 ~ 2026-11-16，1725 条原始记录 → 1213 个交易日）
- 零售价来源：京东平台人工采集 22 条（2026-11-16），其中 9 条规格明确参与单价计算
- 清洗规则：缺失值剔除、同日多等级记录按日均值聚合、IQR 异常检验（未发现异常）、元/斤→元/公斤换算
